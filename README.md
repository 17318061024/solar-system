# 银行太阳系可视化系统

一个基于 Three.js 的交互式 3D 数据可视化项目，展示华为与 20 家银行的交易关系。

## 功能特点

- **中心节点**: 华为（橙色发光球体）位于画面中央
- **银行节点**: 20 家银行均匀分布在周围，按轨道公转
- **双色调设计**: 科技青色（类型A）与紫罗兰色（类型B）交替显示
- **交互效果**:
  - 鼠标悬停：球体放大 1.2 倍、连线高亮、显示交易标签
  - 点击银行：左侧卡片显示详细交易信息
  - 拖拽旋转视角、滚轮缩放
- **视觉效果**:
  - 球体和中心点周围有旋转光环
  - 公转过程中有星星点点粒子散落效果
  - 连线采用贝塞尔曲线，模拟引力效果

## 使用方法

1. 直接用浏览器打开 `index.html` 文件
2. 拖拽鼠标旋转视角
3. 滚轮缩放查看远近
4. 悬停或点击银行球体查看详情

## 提示题（思考题）

1. **数据可视化设计**: 为什么选择太阳系模型来展示银行与华为的交易关系？这种可视化方式的优势和局限是什么？

2. **交互设计优化**: 当前实现了 hover 高亮和点击选中，如果要增加更多交互（比如右键菜单、双击展开详情），应该怎么设计？

3. **性能优化**: 当银行数量增加到 50 家甚至 100 家时，可能会出现性能问题，如何优化？

4. **数据真实性**: 目前使用模拟数据，如果要对接真实交易数据，需要考虑哪些数据安全和隐私问题？

5. **响应式适配**: 当前界面在桌面端显示良好，如何适配移动端触摸操作？

6. **视觉增强**: 除了当前的粒子效果，还能添加哪些视觉效果来增强数据的表现力（比如热力图、动态流向等）？
